Overview

베베드피노는 국내 유아동복 의류 쇼핑몰로, 독특한 느낌의 키치하고 이국적인 디자인이 특징이다.
기존 사이트 메인화면은 처음 방문하는 이용자들에게 생소할 수 있는 브랜드성에 치중되어
사이트 내의 기능과 쇼핑몰 내의 상품을 살펴보기 어려웠다.
해당 불편점을 인지하고 쇼핑몰 본연의 기능에 충실하며 브랜드를 이해할 수 있도록 리디자인을 진행하였다.

Keyword

  • 베베드피노만의 상품

    키치하고 이국적인 독특한 디자인을 강조

  • 차별점 있는 브랜드성

    타 영유아복 브랜드와 확실히 다른 정체성을 부여

  • 참여 가능한 이벤트와 혜택

    이용자의 직관적인 참여를 유도하는 화면 구성

Target Audience

20대 ~ 30대 여성

해당 사이트의 이용자들은 영유아복 구매를 목적으로 하는 20대~30대 여성으로,
타 영유아복 브랜드와 '다른' 차별점이 있는 상품,
즉 독특한 브랜드성이 느껴지는 상품을 구매하기를 바라는 소비자들이다.
따라서 사이트를 방문한 소비자에게 브랜드성을 강조하며, 상품을 소개하고,
쇼핑몰 내에서 이루어지는 이벤트와 혜택들을 소개하여 참여할 수 있도록 화면을 구성한다.

Reference

레퍼런스 대상이 된 사이트들은 국내 유아동 쇼핑몰(에뜨와, 아가방)로,
기존 쇼핑몰 이용자들의 핵심 이용자들과 같은 연령대, 유사한 디자인, 컨셉을 공유한다.
해당 사이트의 이용자들이 메인 사이트 디자인을 좀 더 익숙하게 받아들일 수 있도록
화면 구성(상품 리스트 정렬, 이용자들이 사이트 메인에서 얻기를 바라는 이벤트, 브랜드 정보, 타 사이트로의 링크)에 대한 정보를 반영했다.

Main Page

기존 메인페이지를 국내 쇼핑몰 레이아웃으로 재해석하였다.
상품의 독특한 브랜드성과 함께, 사이트를 방문한 이용자들이
단순 상품 구매 외에도 이벤트 참여, 관련 브랜드 링크 확인, 룩북 탐구 등
다양한 경험을 할 수 있도록 리디자인하였다.

Sub Page

상품 구매화면의 프로토타입으로, 이용자들에게 익숙한 국내 쇼핑몰 레이아웃을 차용하였다.
기존 페이지에서 단순 상품 이미지가 상단에만 위치하여 실제 모델 착용샷을 보기 위해
스크롤을 과하게 내려야 했던 불편함을 개선하였다.
상품 이미지와 정보를 좌우로 배치하여 한 화면에서 주요 정보를
모두 확인할 수 있도록 레이아웃을 재구성하였으며,
착용샷은 상세 정보 바로 아래 배치하여 접근성을 높였다.
